# How to run this?

1. Run this command in the project terminal:
   
    ```bash
    hugo server
    ```
3. If you have not installed hugo yet then follow the below steps:

   1. Follow the official hugo installation guide for your OS and install hugo (Link: https://gohugo.io/installation/)
   2. Verify installation:
      
      ```bash
      hugo version
      ```
4. To check for hugo version:
   
    ```bash
    hugo version
    ```
